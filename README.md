## Native commands
`glass JOURNAL CURSOR region ID INITIAL_STATE`
`glass JOURNAL CURSOR rule ID REGION FROM EVENT TO`
`glass JOURNAL CURSOR intent ID EVENT INPUT ADAPTER CHOICE RECOVERY`
`glass JOURNAL CURSOR outcome INTENT EVENT ARTIFACT RATIONALE`

One outcome event applies every matching regional transition atomically. Explicit source-state matches serve as the first guard language. Intent/outcome pairs preserve planned work and observable results. The listener emits an exact observed-prefix behavior machine.

The first runtime uses a native C++20 journal, file locking, expected cursors, fsync, automatic event reactions, replay, and JSON projections. The byte trace command spells every byte and every bit write under a declared zero-filled MSB-first profile.

`build/glass-publish REPO NEW_RECEIPT_PATH PATH...` stages selected paths, commits on main, pushes main, and records the observed remote head. Transport/reconciliation work receives a queued receipt. Each Git subprocess has a 30-second deadline. A fresh receipt path preserves each attempt.
