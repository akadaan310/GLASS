## Exact science and complexity
Let p be a packed 32-bit pixel. `p XOR mask` is O(1) on fixed-width word architecture. Computing N independent pixels and transmitting/displaying their N output values is generally Omega(N) work or bandwidth, even when parallelized. The goal is a finite number of bitwise operations per changed pixel, sparse dirty rectangles, instancing, shaders and delta compression, **not** claiming the entire rendered surface can be updated in global O(1).

The two conjugate operations from the uploaded PHANTOM Rake project are exact GF(2) transformations with explicit side measurements. A reversible transform requires retention of otherwise lost information. Its exact 8-bit ripple-carry example comprises 40 Boolean gates in the uploaded mathematical packet. These are classical finite-width models. Quantum amplitudes and Fubini–Study distance from the Quantum Oracle V3 attachment are simulated and cannot be replaced by a classical XOR without changing meaning.

## Real 100-source acquisition
The frontier is **not** a verified ranking of worldwide project complexity; complexity depends on declared metrics (source size, AST graph, dependency closure, compiler IR, build cost, semantic coverage, runtime traces). The file is a proposed candidate queue. We cannot establish whether a repository was or was not present in prior AI model training data. Each candidate must be resolved via GitHub API, confirm license, pin commit and then collect at least two witnessed cycles before its behavioral generator is admitted.

Proposed rank after ingestion:
- 20% verified source complexity: node/edge/semantic type cardinalities (normalized per language)
- 25% representation diversity: AST/IR/binary/graphics/physics
- 25% executable witness depth: compiled, traced, replayed
- 15% supported research novelty to the local GLASS registry
- 15% reusable generator extraction yield
The score must not be applied before observed measures exist.

## Media projection
Videos use official embeddable player endpoints when provider policies allow. A remote third-party website can refuse framing using CSP frame-ancestors or X-Frame-Options. No server-side representation bypasses such policies, user authentication or DRM. Fetch only permitted metadata for source trace adapters. Opening another website or accessing personal accounts needs the user's explicit action.

## Evidence
One local source checkout of the standalone UI module passed nine assertions for byte tapes, fixed-word gates, hashes, URLs and guard logic. This checkout was not a device/browser end-to-end test. The GitHub commits were returned by the connected repository tool, and source verification can establish the new bytes exist. Live Vercel publication and YouTube playback on the phone have not been independently verified.
