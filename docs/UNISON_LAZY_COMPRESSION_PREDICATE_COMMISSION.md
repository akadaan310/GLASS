## Compression Oracle & Rolodex
Retain content-addressed immutable objects, typed feature graphs, AST/generator recipes, and per-user alphabet manifests. Admission checks ownership/license. Lazy paging: demand -> lookup -> dependency slice -> decompress/generate only requested objects -> hash verify -> cache with size/TTL rules. Stale RAM cache evicted before immutable disk records; disk evictions only for reproducible cache, not sole durable copies. Use Redis for ephemeral hot-state and PostgreSQL/object storage for durable evidence. Leverage Lucene/OpenSearch/Elasticsearch only when measured indexing needs justify it.

## Search Query Observatory

Record user-supplied query, provider, timestamp, permission, returned URLs/snippets within terms, relevance labels and reproducibility limits.
