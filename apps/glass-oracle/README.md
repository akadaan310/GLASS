# GLASS · Universal Unison Oracle (typing-only website)

The first deployable site is [index.html](index.html). It is a **single self-contained HTML file** with embedded CSS, JavaScript, the user-supplied 28-letter operator registry, 10 modifiers, metaterminal, and an offline Unicode-script snapshot (172 script groups / 778 ranges from a pinned local regex engine; official Unicode 18 reconciliation is a pending admission gate).

No buttons, accounts, model API calls, search results or data uploads. The sole input maps typed text continuously to symbol/constellation sequences. Enter navigates only after complete admitted HTTP(S) URL input. The eight-facet pyramid and cyclic root glyph Rolodex are preserved. The script sky is a **visual typed projection**, not a sourced linguistic translation, search result, or physical cosmic measurement.

**Run:** Open index.html in a browser or serve it with a static HTTPS host. Recommended production path: https://glass.com after *separate authorized DNS and hosting verification*. This commit does not claim glass.com was modified or that browser acceptance passed.
